# Site leve — Pack Stories Harmonie

Versão reconstruída do site de Luciana Camelo, sem dependência do Canva.

## Conteúdo

- código React/TypeScript;
- CSS responsivo;
- imagens otimizadas em WebP;
- três vídeos originais em MP4;
- botões de compra e WhatsApp;
- seções de benefícios, bônus, oferta, garantia e dúvidas frequentes.

## Executar

1. Instale o Node.js 20 ou superior.
2. Execute `npm install`.
3. Execute `npm run dev`.

Para gerar a versão de produção, execute `npm run build`.
